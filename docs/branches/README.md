# Documentation des branches

Chaque branche d'étape a ici un fichier `<nom-de-branche>.md`, qui sert aussi
de description à sa pull request. Rubriques obligatoires :

1. **Objectif** : ce que l'étape change et pourquoi.
2. **Fichiers touchés** : créés, modifiés, supprimés.
3. **Ruptures** : ce qui cesse de fonctionner comme avant (reportées dans `docs/RUPTURES.md`).
4. **Tester** : commandes et vérifications manuelles.
5. **Hors périmètre** : ce qui est volontairement laissé pour plus tard.

Nommage : `e<numéro>-<objet-court>`, en minuscules, sans accents.
